## 三、收录范围判定口诀

1. **资产归属**：域名/产品是否属于字节跳动（中国区）研发/运维 → 否则不收

## 四、特殊类型处理

| 类型 | 处理 |
|------|------|
| AK/SK 泄露 | 直接提交平台（含 AK/SK），由审核验证影响范围与等级，**严禁自行深入业务验证危害** |
| 回显 SSRF | 证明存在且有回显即可（高危1-3），**禁止深入内网渗透** |
| 无回显 SSRF | 差异化响应判断端口 → 中危1；只能 SSRF 本机 → 不超过中危1；Blind 无观察差异 → 低危3 |
| 电商无回显 SSRF | 实际触发方 PSM 归属电商业务范畴则收，否则暂不收（以审核为准） |
| 测试系统 RCE | 无真实业务数据 → 中危1；无法获取服务器权限 → 忽略 |
| 越权读取 | 证明读取数量即可，**真实数据不超过5组**，严禁批量读取；自备测试账号，敏感增删改不涉及线上真实用户 |
