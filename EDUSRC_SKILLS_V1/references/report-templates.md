# EDUSRC 报告模板参考

## 标准漏洞报告模板

```markdown
# [院校名称] - [漏洞简述]

## 漏洞信息
| 项目 | 内容 |
|------|------|
| **漏洞名称** | XXX |
| **漏洞等级** | 严重/高危/中危/低危 |
| **漏洞类型** | XXX |
| **影响范围** | URL/域名/系统名称 |
| **发现时间** | YYYY-MM-DD |
| **Rank估值** | 9~10/7~9/4~7/0~4 |

## 漏洞描述
[技术性描述：系统功能说明、漏洞成因、发现过程概述]

## 影响资产确认
- 目标单位是否在EDUSRC收录范围内：是（教育部/人社部/中科院/省级教育/学校/教育软件）
- 确认依据：[说明判断理由]

## 漏洞复现

### 复现步骤
1. [Step 1]
2. [Step 2]
3. [Step 3]

### HTTP请求/响应包

**请求包：**
```http
GET /path HTTP/1.1
Host: target.edu.cn
User-Agent: Mozilla/5.0 (...)
Accept: */*
Accept-Language: zh-CN,zh;q=0.9

```

**响应包：**
```http
HTTP/1.1 200 OK
Content-Type: application/json

{"sensitive": "data..."}
```

### curl命令（可复现）
```bash
curl -sk -H 'User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36' 'https://target.edu.cn/sensitive/api'
```

## 漏洞影响
1. **影响点1**：[详细说明]
2. **影响点2**：[详细说明]

## 修复建议
### 紧急措施（24小时内）
- [具体措施]

### 短期措施（1周内）
- [具体措施]

### 长期措施
- [具体措施]

## 验证记录
| 端点 | HTTP状态 | 有效 |
|------|----------|------|
| /api/xxx | 200 OK | ✅ |

## 补充说明
- 测试中未修改/删除/增加任何数据
- 测试后已清理所有遗留文件
- 仅进行了无害化验证
```

## 利用链/组合漏洞报告模板

```markdown
# [院校名称] - 多漏洞组合利用链

## 漏洞概述
| 项目 | 内容 |
|------|------|
| **链名称** | XXX |
| **最终等级** | 严重/高危 |
| **漏洞数量** | N个 |
| **影响范围** | URL/域名/系统 |
| **Rank估值** | 9~10 |

## 攻击链路图
```
入口: 漏洞A(信息泄露) → 获取内部系统地址
  ↓
跳板: 漏洞B(未授权) → 访问教务处管理端
  ↓
提升: 漏洞C(越权) → 管理员权限
  ↓
最终: 漏洞D(数据泄露) → 获取全校学生信息
```

### 子漏洞1：[名称]（复现步骤+请求/响应包）
### 子漏洞2：[名称]（同上）
### ...（按链顺序列出，共N个漏洞）

## 最终影响
完整攻击链能达成的效果和危害

## 修复建议
### 紧急：阻断链路入口或关键跳板
### 短期：各漏洞逐一修复
### 长期：建立安全开发生命周期
```

## 文件名命名规则

```
{严重等级}_{漏洞类型}_{院校简称}_{简述}.md

实际例子:
高危_信息泄露_北京大学_工作量计量系统多高危漏洞汇总.md
中危_越权访问_北京大学_UReport2未授权API接口暴露.md
高危_信息泄露_北京大学_应用配置信息及RSA私钥泄露.md
高危_SSRF_北京大学_工作量计量系统JDBC服务端请求伪造.md
```

## 教育行业特定漏洞类型（用于报告）

| 漏洞类型 | 说明 |
|---------|------|
| 信息泄露/学生数据 | 学生个人信息（姓名/学号/身份证/成绩/家庭信息） |
| 信息泄露/教职工数据 | 教职工信息（姓名/工号/工资/职称） |
| 信息泄露/系统配置 | 数据库连接、RSA密钥、OAuth2凭证 |
| 信息泄露/公示数据 | 录取公示、奖学金公示中的敏感信息 |
| 越权访问/教务系统 | 查看/修改他人成绩、课程信息 |
| 越权访问/管理后台 | 未授权进入教务/学工/后勤管理后台 |
| 认证绕过/IAAA | 统一认证系统绕过、CAS令牌伪造 |
| 文件操作/路径穿越 | 任意文件下载、上传、删除 |
| 弱口令/默认密码 | 初始密码规则导致批量撞库 |
| 未授权API | 无需认证的敏感数据API |
| SSRF/内部探测 | 服务端请求伪造探测内网服务 |
| 组件漏洞 | 第三方组件已知漏洞（Shiro/Spring Boot等） |
| 逻辑漏洞/支付 | 缴费支付逻辑缺陷 |
| 信息泄露/公示PDF | PDF公开文件中含敏感信息 |

## 低危报告输出控制

仅在严重→高危→中危全部完成后，且具有组合升级潜力时，才输出低危报告。
