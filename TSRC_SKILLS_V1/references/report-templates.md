# 报告模板参考

## 标准漏洞报告模板

```markdown
# [腾讯产品名称] - [漏洞简述]

## 漏洞信息
| 项目 | 内容 |
|------|------|
| **漏洞名称** | XXX |
| **漏洞等级** | 严重/高危/中危/低危 |
| **漏洞类型** | XXX |
| **影响范围** | URL/域名（属于核心/重点/其他产品） |
| **发现时间** | YYYY-MM-DD |
| **TSRC产品类别** | 核心产品 / 重点产品 / 其他产品 |

## 漏洞描述
[技术性描述：成因、发现过程、攻击者如何利用]

## 漏洞复现
### 复现1：[步骤描述]
```http
GET /path HTTP/1.1
Host: target.example.com

HTTP/1.1 200 OK
{"sensitive": "data..."}
```

### curl 复现命令
```bash
curl -s -X GET "https://target.example.com/path" \
  -H "Host: target.example.com" \
  | head -c 500
```

## 漏洞影响
1. **影响点1**：详细说明

## 修复建议
### 紧急措施（24小时内）
### 短期措施（1周内）
### 长期措施

## 验证记录
| 端点 | HTTP状态 | 有效 |
|------|----------|------|
| /api/xxx | 200 OK | 有效 |

## 测试说明
- 测试中获取的数据量不超过10组
- 测试数据已删除
- 未对内网进行扫描
- 未影响其他用户正常数据
```

## 利用链/组合漏洞报告模板

```markdown
# [腾讯产品] - 多漏洞组合利用链

## 漏洞概述
| 项目 | 内容 |
|------|------|
| **链名称** | XXX |
| **最终等级** | 严重/高危 |
| **漏洞数量** | N个 |
| **影响范围** | URL/域名 |
| **TSRC产品类别** | 核心/重点/其他 |

## 攻击链路图
```
入口: 漏洞A(信息泄露) → 获取凭证
  ↓
漏洞B(未授权) → 访问内部API
  ↓
漏洞C(越权) → 批量获取用户数据
  ↓
最终危害: [严重信息泄露/RCE等]
```

## 各漏洞详情
### 漏洞A：[名称]
...
### 漏洞B：[名称]
...

## 利用条件
1. [前置条件1]
2. [前置条件2]

## 整体影响
根据TSRC评分标准，多漏洞按最高危害评分。
```

## 文件名规范

```
{等级}_{漏洞类型}_TSRC_{简述}.md

示例：
严重_远程代码执行_TSRC_腾讯云API未授权命令执行.md
高危_SQL注入_TSRC_QQ邮箱用户信息泄露.md
中危_未授权访问_TSRC_企业微信管理后台.md
```

## TSRC 高质量报告标准

TSRC对高质量报告额外奖励 50-5000 元现金，要求：

1. **【漏洞标题】** 包含漏洞标题、影响域名、漏洞类型等
   - 例如：`xxx平台xxx域名的xxx漏洞`
2. **【漏洞描述】** 包含漏洞入口、涉及的URL、参数、应用版本等
3. **【复现过程】** 按步骤对工具进行复现，并在过程中体现漏洞的影响与危害
   - 一般以文字截图形式
   - 若使用工具，请提供工具名称
4. **【修复方案】** 请提供可执行的修复建议，如代码修复建议或防护策略
