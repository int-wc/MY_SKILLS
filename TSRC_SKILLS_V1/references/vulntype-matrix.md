## 二、等级判定标准

### [严重] — 积分 9-10

| 类型 | 条件 |
|------|------|
| RCE/代码执行 | 核心产品服务器权限/核心产品客户端权限，可执行任意命令 |
| 严重信息泄漏 | 微信/QQ/王者荣耀等平台，影响用户身份信息安全 |
| 核心逻辑漏洞 | 伪造任意QQ/微信账号发送可自定义内容消息；任意账号密码更改 |
| 直接影响现金 | 可直接提现，无利用限制，影响超10万 |
| SQL注入→系统权限 | 获取可执行权限 |
| 缓冲区溢出/获取root/集群权限 | 核心产品 |
| 服务器级别关键凭证 | AK/SK/证书/密钥可登录CVM |

### [高危] — 积分 6-8

| 类型 | 条件 |
|------|------|
| 存储XSS | 核心产品/低交互易传播/可影响大量用户（QQ空间/QQ邮箱/企业邮箱/Web微信/公众号） |
| SQL注入 | 可读取数据库表字段名 |
| 未授权管理后台 | 访问并使用管理员功能 |
| 信息泄漏 | 3+敏感字段，且 >1w条 |
| 客户端RCE | 远程任意命令执行/可利用UAF/内核代码执行 |
| 全回显SSRF | 可访问腾讯内网且获取回显 |
| 重要系统越权 | 越权操作他人账号全部/核心功能 |
| 任意文件读写 | 全站COS任意文件读写/覆盖 |
| 客户端拒绝服务 | 核心产品，永久性 |

### [中危] — 积分 3-5

| 类型 | 条件 |
|------|------|
| 需交互XSS/CSRF | 存储型XSS、重要敏感操作CSRF |
| 信息泄露 | 客户端明文存密码/QQ密码明文传输/源码压缩包泄露 |
| SSRF（无回显） | 可访问内网但无回显 |
| DOM型XSS | 需要交互、特定条件 |
| 任意文件读取 | 不可写或无法进一步利用 |
| JSONP劫持 | 敏感信息 |
| 本地代码执行 | 堆栈溢出/UAF/double free/DLL劫持 |
| 子域名劫持 | qq.com/tencent.com |
| 非核心SQL注入 | 少量或无敏感数据 |
| 微信小程序密钥泄露 | 可调用危害较大API |

### [低危] — 积分 1-2

| 类型 | 条件 |
|------|------|
| 反射XSS | 仅特定非流行浏览器环境 |
| 轻微信息泄露 | GitHub源码/密码/SVN/phpinfo/内网账号密码 |
| URL跳转 | qq.com/tencent.com/wechat.com等重要子域名 |
| 短信轰炸 | 绕过封控，单号3分钟50+条 |
| 暴力破解 | 账户密码 |
| 盲SSRF | 无回显无法请求内网 |

### [无] — 积分 0

Bug、Self-XSS、无意义CSRF/越权、无意义源码泄漏、用户名遍历、SPF邮件伪造、401钓鱼、PDF XSS、邮箱轰炸、本地拒绝服务、无意义API Key泄露、无法复现的报告

## 三、TSRC 特殊规则速查

| 规则 | 说明 |
|------|------|
| 大模型 | 仅收录信息安全漏洞，拒绝内容安全/越狱/Prompt注入/幻觉 |
| SSRF | 使用 `http://tst.woa.com/flag.html` 或 `http://9.138.237.216/flag.html`；不区分业务一律重点产品计分 |
| AK/SK泄露 | 仅验证有效性，不得深入验证危害，由审核确认 |
| 沙箱逃逸 | 容器逃逸到宿主机/物理机，或证明可通腾讯内网，才正常评分 |
| 客户端漏洞 | 内部已知2个发版周期内不予奖励；需提供POC+验证视频+详细分析 |
| 合并同类 | 同功能增删改查应合并提交；同JS多个XSS合并；同框架整站CSRF合并 |
| 利用链 | 按最大危害评分：如后台弱口令+命令执行=仅按命令执行计分 |
| 用户量门槛 | 高/严重：存量<10%不收录；中低危：存量<50%不收录 |
| 金融漏洞 | 需提供物流单号/虚拟商品ID/金额到账截图等实际证明 |
| 第三方库 | 通过升级即可修复的客户端第三方库漏洞，仅首个报告者计分 |
