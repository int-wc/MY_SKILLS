# 厂商 VulnType 速查矩阵

本文件列出各专属SRC厂商接受的漏洞类型和严重等级定义，来源于 `audit_reports.py` 中的 `VULN_TYPES` 字典及各公司的 `VulnType.html`。

读取厂商信息时，优先以 `{公司}/VulnType.html` 为准；若该文件不存在，以本矩阵为参考。

## 使用说明

1. 每家公司在 `Exclusive_SRC/{公司名}/` 下有 `VulnType.html`（或 `Vuln_Type.html`）文件，包含补天平台上的完整漏洞类型定义
2. 若 VulnType.html 不存在，以 `*_Information.html` 中的描述为准
3. 本矩阵是 `audit_reports.py` 中字典的人工可读版本，与脚本保持同步
4. **注意：** 以"忽略"/"不接收"列中的类型提交报告将被直接拒绝
